# Фаза 2 — чек-лист ручного тестирования

Ручные кейсы к [`phase-2-editing.md`](phase-2-editing.md). Автотесты (`scripts\test.bat`,
39 кейсов) покрывают логику ядра; здесь — UI, звук и сценарии «живьём» на машине
с микрофоном (ASIO/WASAPI). Готовность фазы: **откат до старта после рестарта**
(раздел F). Отмечайте `[x]` и фиксируйте расхождения.

## C. Операции правки (каждая: применить → Ctrl+Z → Ctrl+Y)

Перед каждой группой: записать свежий тейк 3–5 сек с паузами в начале/конце (для трима), кликнуть клип.

| # | Операция | Шаги | Ожидание после применения | После Ctrl+Z / Ctrl+Y |
|---|---|---|---|---|
| C1 | Разделить (`S`) | Курсор по линейке в середину клипа → `S` | Два клипа, длины в сумме равны исходной; новый называется `TAKE-NN.1` | 1 клип / снова 2 |
| C2 | Трим тишины | «Правка → Трим тишины по краям» | Тишина по краям срезана, клип короче, старт сдвинулся на величину среза | Возврат к исходной длине / снова короткий |
| C3 | Обрезка вне диапазона | Клик по линейке в начале речи + `Shift+клик` в конце → «Обрезать вне диапазона» | Остаётся только диапазон | Полный клип / обрезанный |
| C4 | Тишина | Выделеть диапазон внутри → «Тишина» | Участок ровный (нулевая линия) | Волна восстановлена |
| C5 | Реверс | «Реверс» (без диапазона — весь клип) | Волна зеркальная, слышится задом наперёд | Исходная |
| C6 | Нормализация | «Нормализовать…» → −3.0 | Подпись Peak ≈ −3.0 dB, звук громче | Прежний пик |
| C7 | Усиление | «Усиление…» → +6 | Подпись «Gain 6.0 dB», звук громче, **волна не меняется** (гейн при рендере) | Подпись исчезает / появляется |
| C8 | Фейд-ин | Курсор на ~0.5 сек → «Фейд-ин до курсора» | Жёлтые линии-«крылья» от старта до курсора | Линии исчезают |
| C9 | Фейд-аут | Курсор ближе к концу → «Фейд-аут от курсора» | Крылья к концу клипа; на плейбеке плавное затухание | — |
| C10 | Кроссфейд | `S`-разрезать клип, правую половину передвинуть так, чтобы она перекрывала левую → выбрать левый → «Кроссфейд с перекрывающимся клипом» | Клипы слиты в один, в зоне перекрытия плавный переход, дорожка вторая исчезла | Снова два клипа |
| C11 | Ошибки | «Fit to Ref» у тейка, записанного на реплику без референса; «Трим тишины» у клипа из тишины; операции без выбранного клипа | Понятное сообщение, состояние и счётчики не меняются | — |
