# Лицензии сторонних компонентов

Заполняется по мере подключения зависимостей (Фаза 0, п.5 первого промпта).

| Компонент | Лицензия | Тип интеграции | Статус |
|---|---|---|---|
| `RtAudio` | `MIT` | линковка в ядро | запланировано |
| `ASIO SDK 2.3.4` | Dual: Proprietary / `GPLv3` | внешний исходник (`ASIO-SDK_2.3.4_2025-10-15/ASIOSDK` → `common/` + `host/` + `host/pc/`), НЕ коммитить | зафиксировать текст лицензии сюда после сборки |
| `vgmstream` | `GPL` (проверить точную версию в репо) | внешний `CLI` через `subprocess`, в ядро НЕ линковать | запланировано |
| `sound2wem` (`https://github.com/EternalLeo/sound2wem`, `third_party/sound2wem`) | зафиксировать сюда из репо-источника после клонирования | внешний исходник, сборка `sound2wem.exe`, вызов как `subprocess` | запланировано |
| `libsndfile` / `dr_wav` / `SoXR` / `RubberBand` / `Eigen` | зафиксировать сюда | линковка в ядро (только open-source без `GPL`-заражения) | запланировано |
| `nlohmann::json` / `Catch2` | зафиксировать сюда | header-only / тесты | запланировано |
